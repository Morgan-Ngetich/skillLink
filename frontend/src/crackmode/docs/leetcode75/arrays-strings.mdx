## Patterns to Learn

### Two Pointers
**Use start and end pointers to solve problems efficiently**

Two pointers technique involves using two index variables to traverse data structures. This approach is particularly powerful for:
- Palindrome checking
- Array reversal
- Finding pairs with target sum
- Removing duplicates

**Example scenario:** Checking if a string is a palindrome by comparing characters from both ends moving inward.

### Sliding Window
**Handle substrings/subarrays with dynamic window size**

The sliding window technique maintains a window of elements and slides it across the data structure. Perfect for:
- Maximum sum subarray problems
- Longest substring without repeating characters
- Finding anagrams in strings
- Minimum window substring

**Example scenario:** Finding the maximum sum of k consecutive elements in an array.

### Hashing/Counting
**Use frequency maps for character or number counting**

Hash maps provide O(1) lookup time and are essential for:
- Anagram detection
- Finding duplicates
- Character frequency counting
- Two sum problems

**Example scenario:** Determining if two strings are anagrams by comparing character frequencies.

### Merge Strings Alternately

**Difficulty:** Easy  
**Problem:** You are given two strings `word1` and `word2`. Merge the strings by adding letters in alternating order, starting with `word1`. If a string is longer than the other, append the additional letters onto the end of the merged string.

#### Approach
Use two pointers to iterate through both strings simultaneously, alternating between characters. Handle remaining characters after one string is exhausted.

#### Solution

```javascript
function mergeAlternately(word1, word2) {
    let result = '';
    let i = 0, j = 0;
    
    // Alternate between characters while both strings have characters
    while (i < word1.length && j < word2.length) {
        result += word1[i++];
        result += word2[j++];
    }
    
    // Add remaining characters from word1
    while (i < word1.length) {
        result += word1[i++];
    }
    
    // Add remaining characters from word2
    while (j < word2.length) {
        result += word2[j++];
    }
    
    return result;
}

// Example usage:
// mergeAlternately("abc", "pqr") → "apbqcr"
// mergeAlternately("ab", "pqrs") → "apbqrs"
```

**Time Complexity:** O(m + n) where m and n are the lengths of the input strings  
**Space Complexity:** O(m + n) for the result string

### Greatest Common Divisor of Strings

**Difficulty:** Easy  
**Problem:** For two strings `s` and `t`, we say `t` divides `s` if and only if `s = t + t + t + ... + t` (i.e., `t` is concatenated with itself one or more times). Given two strings `str1` and `str2`, return the largest string `x` such that `x` divides both `str1` and `str2`.

#### Approach
Use the mathematical property that `gcd(a,b) = gcd(b, a%b)` applied to strings. First verify if a common divisor exists by checking if concatenating the strings in different orders yields the same result.

#### Solution

```javascript
function gcdOfStrings(str1, str2) {
    // Check if concatenation works both ways
    // If str1 + str2 !== str2 + str1, no common divisor exists
    if (str1 + str2 !== str2 + str1) {
        return '';
    }
    
    // Helper function to find GCD of two numbers
    const gcd = (a, b) => b === 0 ? a : gcd(b, a % b);
    
    // Find GCD of the lengths
    const gcdLength = gcd(str1.length, str2.length);
    
    // Return the substring of that length
    return str1.substring(0, gcdLength);
}

// Example usage:
// gcdOfStrings("ABCABC", "ABC") → "ABC"
// gcdOfStrings("ABABAB", "ABAB") → "AB"
// gcdOfStrings("LEET", "CODE") → ""
```

**Time Complexity:** O(min(m, n)) for the GCD calculation  
**Space Complexity:** O(min(m, n)) for the substring creation

### Kids With the Greatest Number of Candies

**Difficulty:** Easy  
**Problem:** There are `n` kids with candies. You are given an integer array `candies`, where each `candies[i]` represents the number of candies the `i`th kid has, and an integer `extraCandies`, denoting the number of extra candies that you have. Return a boolean array `result` of length `n`, where `result[i]` is `true` if, after giving the `i`th kid all the `extraCandies`, they will have the greatest number of candies among all the kids, or `false` otherwise.

#### Approach
Find the maximum number of candies any kid currently has. Then check if each kid can reach or exceed this maximum when given the extra candies.

#### Solution

```javascript
function kidsWithCandies(candies, extraCandies) {
    // Find the maximum candies any kid currently has
    const maxCandies = Math.max(...candies);
    
    // Check if each kid can have >= maxCandies with extra candies
    return candies.map(candy => 
        candy + extraCandies >= maxCandies
    );
}

// Alternative approach without spread operator (more efficient for large arrays)
function kidsWithCandiesOptimized(candies, extraCandies) {
    let maxCandies = 0;
    
    // Find maximum in single pass
    for (let candy of candies) {
        maxCandies = Math.max(maxCandies, candy);
    }
    
    // Create result array
    const result = [];
    for (let candy of candies) {
        result.push(candy + extraCandies >= maxCandies);
    }
    
    return result;
}

// Example usage:
// kidsWithCandies([2,3,5,1,3], 3) → [true,true,true,false,true]
// kidsWithCandies([4,2,1,1,2], 1) → [true,false,false,false,false]
```

**Time Complexity:** O(n) where n is the number of kids  
**Space Complexity:** O(1) excluding the output array

When approaching array and string problems:

1. **Identify the pattern** - Is this a two-pointer, sliding window, or hashing problem?
2. **Consider edge cases** - Empty arrays/strings, single elements, duplicates
3. **Optimize step by step** - Start with brute force, then optimize
4. **Analyze complexity** - Always consider both time and space complexity
